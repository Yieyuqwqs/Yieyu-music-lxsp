# 宪法（S 级，不可协商）

> 逐条拆分的版本见：[docs/constitution/README.md](./docs/constitution/README.md)（十条总表 + 每条一个文件）
> 任何改动前先读总表，并按第九条先发改动清单。

本仓库的任何代码改动都必须遵守以下条款。违反任何一条，等于交付失败。

## 第一条：禁止补丁式开发

**禁止**以下行为（一律视为补丁）：
- 加一个 `if (x) return` / `try/catch` 把异常吞掉来"让界面不报错"
- 改某个常量/阈值/超时来掩盖时序问题
- 在症状发生处拦截，而不动产生症状的那一层
- "先这样，回头再优化"——没有回头

**要求**：每次修复必须先给出**根因证据**（日志、实测、代码引用点），再做**结构性修改**：
改的是产生问题的机制，不是问题的表象。

## 第二条：每次修复必须四件套齐全

1. **根因**：一句话说清"为什么必然出错"，附证据（CI 日志行号 / 实测数据 / 代码位置）
2. **不变量**：这次改动之后，系统多了哪条不可破坏的规则
3. **测试**：把不变量写成测试放进 `tests/lxsp/`，CI 每次跑
4. **回退**：如果新机制失效，退化路径是什么（不能是"就坏了"）

缺任何一件，等于没修。

## 第三条：状态只有一个来源

- 房间号：只来自本地的 create/join 入参；对端消息里的房间号只用于校验
- 房间状态：只有房主能写；guest 只读，且只接受 `version` 更大的状态
- 切房/切模式/离开：必须走 `resetSession()` 原子清理，禁止"只关一半"

## 第四条：引用必须验证，不能靠记忆

- 新增/改名函数后，必须同时验证：**定义存在** + **调用点存在** + **import 存在**（三处 grep）
- UI 调用的 service 方法、status 字段，由 `tests/lxsp/contract-listen-together.test.mjs` 强校验
- 面板必须有错误边界，单块故障不得拖垮整页

## 第五条：性能改动必须带实测数据

- 报告格式固定：`最小 / P50 / P90 / 最大`，并注明样本数与测试路径
- 必须写清这是"实测"、"理论推算"还是"未接上"，三种不许混说
- 每次改动都附完整延迟表（用户要求：每轮都给）

## 第六条：构建失败只修根因

- 编译错误 → 只修引起它的那一处，不顺手改别的
- 不许用 `-w`、`#if 0`、注释掉代码来绕过编译错误

## 第七条：不许留未完成的临时方案

任何 `TODO` / 临时开关，必须在同一次交付内完成或删除；否则不许提交。

## 第八条：诚实高于好看

- 没验证过的，就说没验证（例：真机未测、打洞成功率未知）
- 测试全绿但真机白屏，说明测试覆盖不足 → 补测试，不是补代码


## 第九条：改动清单纪律（报告前置）

任何提交前，必须先给出**改动清单**，逐条列明：

| 位置 | 改动 | 性质 | 配套测试 |
|---|---|---|---|
| 文件:函数 | 代码/行为 | 不变量 / 幂等 / 结构重构 / 【禁止】 | 测试名 |

规则：
1. **每一个新增的 `if` / `try` / 常量变更，都必须出现在清单里并标注性质**
2. 性质只能是不变量、幂等、结构重构；若是"吞异常/改阈值绕过/掩盖缺失数据"，立刻删除
3. 清单里出现的禁止性质 = 本次交付不合格
4. 先发清单，再动手；不允许先写代码后补报告

违反本条视为不合格交付。


## 第十条：CI 必须解析到每一个模块（禁止覆盖死区）

1. 每个被修改的 `.ts`/`.tsx` 文件，都必须被 `tests/lxsp/modules.test.mjs` 解析一遍
   （babel，TS+JSX）；解析失败即构建失败，不允许"测试全绿但代码有语法错误"。
2. 解析器加载失败也必须判红（不许静默跳过检查）。
3. 新增测试必须先在**人为注入缺陷**的情况下验证会变红，否则视为无效测试。
4. 禁止用正则批量改写源码；改动必须逐点手写并逐点验证（定义/import/调用三处）。


## 第十一条：严禁温室测试，必须真机/真实链路闭环

1. 涉及网络请求/底层播放/跨进程通信的修复，禁止仅凭 Mock 判定"全绿"
2. 解析、换源必须在测试里拉**真实线上直链**，验证 HTTP 200/206 与真实字节
3. 底层报错必须给 Logcat；拿不到日志就必须 `reportError` 抛出真实异常，禁止静默吞
4. 测试里出现 mockPlayer/fakeUrl 之类，必须有 `// human-exempt: <理由>` 且经人类审批

---

违反以上任一条，视为不合格交付。
