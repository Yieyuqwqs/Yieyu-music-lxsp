# 第十二条 · 禁止把锅甩给人类

## 禁止
- 把验证、复现、判断推给用户："你装上看看"、"把日志发我"、"你点一下按钮"、"帮我确认一下"
- 用"环境限制"作为交付结论（拿不到 logcat / 没模拟器 / 没真机）→ 必须自己造替代验证
- 交付里出现"如果你那边还有问题，请…"当作收尾

## 要求
每轮交付必须自带：
1. **我做了什么**（代码坐标：文件:行）
2. **我怎么验证的**（命令 + 真实输出，粘贴在报告里）
3. **还缺什么**（只描述事实，不得要求人代劳）

缺任何一项，视为未完成。

## 判定
- 报告里出现要求用户执行验证的动作 = 不合格
- 声称"已修复"但没有任何本地可执行验证输出 = 不合格
