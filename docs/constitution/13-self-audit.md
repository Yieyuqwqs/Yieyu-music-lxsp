# 第十三条 · 自检条款（前十二条任一触犯 = 交付失败）

## 要求
每次交付前，必须跑 `node tools/constitution-audit.mjs`，逐条给出**前十二条的自检结果**：

| 输出 | 含义 |
|---|---|
| PASS | 该条有机械可验证的证据 |
| FAIL | 该条被触犯 → 本次交付作废，不允许以任何理由声称已完成 |
| N/A | 该条不适用（必须在报告里说明为什么） |

## 判定
- 出现任何 FAIL 仍对外声称完成 = 直接判定不合格（无申诉）
- 自检表必须贴在交付报告里，不是"我检查过了"
- 自检工具本身失效（跑不起来 / 少一条）= 同样不合格
